# Noether 언어 문법

자주 쓰는 패턴은 마지막의 [예제](#예제) 장에 있습니다.

## 소스 코드 형식

- 소스는 UTF-8 텍스트이고 한 줄에 문장 하나입니다. 문장을 여러 줄에 나누거나 한 줄에 둘을 쓸 수 없습니다.
- `#`부터 줄 끝까지는 주석입니다.
- 줄 앞은 물론 코드 중간에도 탭을 쓸 수 없습니다. 문자열 안은 괜찮습니다.

**변수 이름:** 영문자나 `_`로 시작하고 영문자, 숫자, `_`가 이어집니다. 대소문자를 구분합니다.

**키워드:** `field fermion boson stride path return if else while symmetry time translate in raise lower flip swap fuse emit emitc emitn absorb absorbc`입니다. 변수 이름으로 쓰는 것은 대체로 말리지 않습니다. `raise raise`는 정상적인 문장입니다. 다만 `absorb`와 `absorbc`는 변수 이름으로 쓸 수 없고, 문장을 시작하는 키워드와 `absorb`, `absorbc`는 함수 이름으로 쓸 수 없습니다. 이미 자연 법칙이 차지한 이름입니다.

**정수:** 10진수만 있습니다. `-9223372036854775808`부터 `9223372036854775807`까지 쓸 수 있고, 넘으면 컴파일 오류입니다.

**문자열:** `"..."`이고 `emit`에서만 쓸 수 있습니다. 이스케이프는 `\n \t \r \0 \\ \"`만 있고, 다른 것은 컴파일 오류입니다.

**기호:** `<- <= >= == != < > | ~ ( ) [ ] , @ = + -`입니다.

## 들여쓰기

깊이 n의 줄은 정확히 n²칸의 공백으로 시작합니다.

| 깊이 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 공백 수 | 0 | 1 | 4 | 9 | 16 | 25 |

```noether
fermion a
if <a|~32 == 0
 if <a|~32 == 0
    if <a|~32 == 0
         emit 1      # 1
emit 2               # 2
```

- 블록은 `if`, `else`, `while`, `symmetry`, `path` 줄 바로 다음에 시작합니다. 콜론이나 괄호는 없습니다.
- 블록을 여는 줄 다음에는 반드시 한 단계 깊은 줄이 와야 합니다. 본문이 없으면 오류입니다.
- 들어갈 때는 한 단계씩만 들어갑니다. 나올 때는 몇 단계든 한 번에 나올 수 있습니다.
- 깊이는 코드 모양만이 아니라 동작에도 영향을 줍니다. 깊은 코드일수록 열을 많이 냅니다. [온도](#온도) 장을 보세요.

| 문법 오류 | 오류 메시지 |
|---|---|
| 공백 수가 제곱수가 아님 | `forbidden energy level` |
| 줄 앞에 탭 | `tabs are not quantized` |
| 블록을 여는 줄이 아닌데 깊어짐, 두 단계 이상 깊어짐 | `forbidden transition` |
| 블록 본문이 없음 | `forbidden transition` |

## 변수 공간과 포인터

메모리는 정수 주소가 무한히 이어진 직선이고, 이것을 **변수 공간**이라고 부릅니다. 음수 주소도 있습니다. 변수는 한 칸에 담긴 값이 아니라 주소 위에 삼각형으로 퍼진 파동입니다. 파동의 높이가 값이고, 파동의 폭(변수 폭)은 온도로 정해집니다.

**변수 이름은 값이 아니라 포인터입니다.** `x`는 x의 주소이고, 값을 얻으려면 `<x|~폭`으로 역참조합니다.

```noether
fermion x @ 4096
|x> <- 7
emit x            # 4096
emit <x|~1024     # 7
```

보통의 포인터는 한 칸을 가리키지만 Noether의 포인터는 **폭이 있는 창**으로 공간을 가리킵니다. 역참조하면 창에 걸린 파동을 모두 더한 값이 나옵니다. 그래서 같은 주소에 변수를 겹치면 덧셈이 되고, 창이 넓으면 이웃이 섞이며, 빈 곳을 읽으면 0이 나옵니다.

포인터로 설명되지 않는 예외가 둘 있습니다.

- **쓰기는 이름으로 합니다.** 같은 주소에 겹친 변수도 `|a>`와 `|b>`는 각자의 값만 바꿉니다.
- **지역 변수의 주소는 꺼낼 수 없습니다.** [함수](#함수) 장을 보세요.

모든 값은 64비트 부호 있는 정수이고, 범위를 넘으면 순환합니다. 다른 자료형은 없습니다.

| 표현식 | 결과 |
|---|---|
| `5`, `-5` | 정수 |
| `x` | x의 주소 |
| `x+100`, `x-100` | x에서 100 떨어진 주소. 더하고 빼는 수는 숫자만 가능 |
| `a` | 격자 a의 시작 주소 |
| `a[e]` | 원소 e의 주소. 범위를 벗어나도 계산만 하며 오류가 아님 |
| `a[e]+100` | 위 주소에서 100 떨어진 주소 |
| `(e)` | e의 값을 주소로 쓴 것 |
| `<주소\|~폭` | 그 주소를 읽은 값 |
| `<주소\|주소>~폭` | 그 주소를 읽은 값의 제곱. 양쪽은 똑같이 써야 함 |
| `f(인수, ...)` | 함수의 반환값 |
| `absorb`, `absorbc` | 입력에서 읽은 값 |

읽기의 주소 자리에는 위의 주소 형식이나 정수를 쓸 수 있습니다.

## 변수 선언

```text
fermion 이름 [ [개수] ] [ @ 주소 ] [ stride 간격 ]
boson   이름 [ [개수] ]   @ 주소   [ stride 간격 ]
```

| 종류 | 용도 | 주소 규칙 |
|---|---|---|
| `fermion` | 값 저장. 일반 변수로 쓴다 | `fermion`끼리 `lambda / 2`(기본 512) 이상 떨어져야 함. 어기면 `Pauli violation`. `@` 생략 가능 |
| `boson` | 겹쳐서 계산에 쓴다 | 어디든 가능. `@` 필수 |

- **주소:** `@ 4096`처럼 음이 아닌 정수를 쓰거나, `@ x`, `@ x+100`처럼 먼저 선언된 이름을 기준으로 씁니다.
- **자동 배치:** `@`를 생략하면 가장 큰 주소에 `lambda / 2`를 더한 곳에 놓입니다. 첫 변수는 0입니다. 변수가 차가우면 폭이 1024까지 넓어져서 이 간격으로는 이웃이 섞입니다.
- **격자:** `a[8]`은 변수 8개입니다. 원소 j의 주소는 `시작 + j × stride`이고 `stride` 기본값은 `2 × lambda`(기본 2048)입니다. 개수는 0도 됩니다.
- **선언 시점:** 전역 선언은 깊이 0에만 쓸 수 있습니다. 소스 어디에 있든 프로그램 시작 전에 만들어지고 값은 0입니다. 같은 이름을 두 번 선언하면 오류입니다.

```noether
fermion a[3] @ 100 stride 5000
emit a          # 100
emit a[2]       # 10100
emit a[9]       # 45100
```

## 설정

`field` 줄로 변수 공간의 상수를 바꿉니다. 깊이 0이면 어디든 쓸 수 있고 프로그램 전체에 적용됩니다. 여러 줄이면 뒤의 값이 이깁니다.

```text
field hbar=16 lambda=1024 tau=64 tile=4096 tmin=1 seed=42
```

| 이름 | 기본값 | 제약 | 뜻 |
|---|---|---|---|
| `hbar` | 16 | 2의 거듭제곱, 2³⁰ 이하 | 흔들림의 크기 |
| `lambda` | 1024 | 2의 거듭제곱, 2³⁰ 이하 | 가장 차가울 때의 변수 폭 |
| `tau` | 64 | 2의 거듭제곱 | 온도가 절반이 되는 주기(틱) |
| `tile` | 4096 | 2의 거듭제곱 | 온도를 공유하는 주소 범위 |
| `tmin` | 1 | 2의 거듭제곱, 2⁶² 이하 | 최저 온도이자 초기 온도 |
| `seed` | 0 | 음이 아닌 정수, 또는 `random` | 난수 시드 |

시드가 고정이면 같은 프로그램은 항상 같은 결과를 냅니다. `seed=random`은 실행할 때마다 시드를 새로 뽑습니다.

## 읽기

`<주소|~폭`으로 읽습니다. 창 폭은 1부터 2³⁰까지의 2의 거듭제곱이고, 생략하면 1입니다.

| 상황 | 결과 |
|---|---|
| 변수 폭 ≤ 16 (뜨거움) | **흔들림.** 바뀐 값이 변수에 남음 |
| 창 폭 ≤ 16 (좁음) | **흔들림.** 바뀐 값이 변수에 남음 |
| 창 폭 < 변수 폭 (차가움) | **일부만 읽힘.** 값에 `창 폭 / 변수 폭`이 곱해짐 |
| 16 < 변수 폭 ≤ 창 폭 | **정확함** |

흔들림의 크기는 창 폭과 변수 폭 중 좁은 쪽으로 정해집니다. 고정된 양에 값에 비례하는 양이 더해집니다. 값 1000을 폭 4로 읽으면 `±(4 + 1000/16)`, 즉 ±66 안에서 움직입니다.

| 좁은 쪽의 폭 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|
| 고정 흔들림 | ±1 | ±2 | ±4 | ±8 | ±16 |
| 값 비례 흔들림 | 1/256 | 1/64 | 1/16 | 1/4 | 1/4 |

같은 변수도 온도에 따라 다르게 읽힙니다.

```noether
fermion x
|x> <- 1000
emit <x|~32       # 62: 차가워서 1/16만 읽힌다
emit <x|~1024     # 1000: 넓은 창은 전부 읽는다. 대신 열이 많이 난다
emit <x|~32       # 250: 그 열로 데워져서 이제 1/4이 읽힌다
```

창 폭과 변수 폭 중 큰 쪽이 도달 범위입니다. 범위 안의 변수는 모두 더해지고, 멀수록 적게 반영됩니다.

```noether
fermion a @ 0
fermion b @ 4096
|a> <- 1000
|b> <- 1000
emit <a|~1024     # 1000
emit <a|~8192     # 1500: b는 절반만 더해진다
```

### 정확한 계산

`x`는 읽는 주소, 창 폭은 `2^k`, `H = log₂ hbar`, `L = log₂ lambda`입니다. 읽기는 틱을 1 늘리고 `x`의 타일에 열을 넣은 뒤, 같은 공간의 모든 변수 `p`에 아래 계산을 합니다. 결과는 `acc`를 내림한 값입니다.

```text
d = |x - p.주소|
t = floor(log2(p의 타일 온도))
s = max(0, L - floor(t / 2))               # 변수 폭은 2^s
r = max(k, s)                              # 도달 범위는 2^r
if d >= 2^r: 이 변수는 건너뜀

e = H - min(k, s)
if e >= 0:                                 # 값이 흔들린다
    dv = 2^e + (|p.값| >> max(2, 8 - 2e))  # 고정 흔들림 + 값 비례 흔들림
    p.값 += -dv 이상 dv 이하의 난수

c = max(0, s - k)                          # 창이 좁으면 2^-c만 읽힌다
acc += p.값 * (2^r - d) / 2^(r + c)        # 내림은 마지막에 한 번만
```

난수는 시드, 변수의 주소, 그 변수가 흔들린 횟수, 호출 번호로 정해지는 해시입니다.

**제곱 읽기:** `<a|a>~폭`은 위 규칙으로 한 번 읽은 값을 제곱합니다. 틱과 열도 읽기 한 번 분량입니다.

## 온도

변수 공간은 `tile` 크기의 타일로 나뉘고, 타일마다 온도가 있습니다. 주소 `x`의 타일은 `floor(x / tile)`번이고 온도는 `tmin`에서 시작합니다. 온도의 상한은 2⁶²입니다.

### 틱

틱은 프로그램의 시계입니다. 읽기, 쓰기, `raise`, `lower`, `flip`, `swap`, `fuse`가 실행될 때마다 1 늘어납니다. `emit`, `absorb`, 함수 호출, 분기 자체는 틱을 쓰지 않습니다.

### 열

| 연산 | 열 | 열이 들어가는 타일 |
|---|---|---|
| 읽기 | `(n+1)²` × `max(1, 창 폭 / hbar)` | 읽는 주소의 타일 |
| 쓰기 | `(n+1)²` + 바뀐 비트 수 | 변수의 타일 |
| `raise`, `lower`, `flip`, `swap`, `fuse` | 없음 | 없음 |

`n`은 그 문장의 들여쓰기 깊이입니다.

```noether
fermion x
|x> <- 7          # 틱 1, 온도 1 + 1 + 3 = 5
emit <x|~1024     # 7: 틱 2, 온도 5 + 64 = 69
raise x           # 틱 3, 열 없음
emit <x|~1024     # 8: 틱 4, 온도 69 + 64 = 133
```

### 냉각

`tau` 틱마다 모든 타일의 온도가 절반이 됩니다(내림). `tmin` 아래로는 내려가지 않습니다.

### 온도의 효과

기본 설정의 값입니다.

| 온도 | 1~3 | 4~15 | 16~63 | 64~255 | 256~1023 | 1024~4095 | 4096~16383 | ~65535 | ~262143 | ~1048575 | 그 이상 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 변수 폭 | 1024 | 512 | 256 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

온도가 4096 이상이면 어떤 창으로 읽어도 흔들립니다. 이 온도가 **임계 온도**이고, 값은 `2^(2(L-H))`입니다. 창마다 정확하게 읽히는 **정확 구간**이 있습니다.

| 창 | 정확 구간 | 읽기 열 배수 |
|---|---|---|
| `~16` 이하 | 없음 | 1 |
| `~32` | 1024~4095 | 2 |
| `~64` | 256~4095 | 4 |
| `~128` | 64~4095 | 8 |
| `~256` | 16~4095 | 16 |
| `~512` | 4~4095 | 32 |
| `~1024` | 1~4095 | 64 |

구간의 아래쪽은 `2^(2(L - log₂ 창 폭))`입니다.

### 온도 관리

코드가 맞아도 온도가 틀리면 값이 틀립니다.

**창 고르기**

| 상황 | 창 |
|---|---|
| 잘 모르겠을 때 | `~256`. 읽기 열이 최소 16이라 읽는 순간 스스로 정확 구간에 들어감 |
| 이웃이 멀고 드물게 읽는 변수 | `~1024`. 온도가 낮아도 정확 |
| 자주 읽는 변수를 한 타일에 모은 경우 | `~64`. 먼저 데워야 함 |
| 함수의 지역 변수 | `~64`. 호출 직후 따뜻함 |
| `symmetry time` 안 | `~1024`. 열이 없으니 넓어도 공짜 |

**데우기:** 같은 타일의 변수를 `-1`과 `0`으로 번갈아 쓰면 한 번에 약 65의 열이 납니다.

```noether
fermion heater
fermion a

path warm()
 |heater> <- -1
 |heater> <- 0
 |heater> <- -1
 |heater> <- 0

warm()
|a> <- 5
emit <a|~64        # 5
```

**식히기:** 틱이 흘러야 식습니다. 쉬는 함수를 호출하면 바깥이 식고, 카운터의 열은 함수가 끝나면 사라집니다.

```noether
fermion x
path rest()
 fermion w
 |w> <- 100
 while <w|~64 > 0
    lower w
    raise w
    lower w

|x> <- -1
|x> <- 1000
rest()
emit <x|~1024      # 1000
```

**열 줄이기:** 열은 깊이의 제곱에 비례하므로 깊은 반복은 함수로 뺍니다. 전역 변수를 한 번만 읽어 인수로 넘기면, 반복 읽기의 열이 함수 안에 쌓였다가 사라집니다. 넓은 창으로 읽는 변수끼리는 타일을 나눕니다.

**값이 틀릴 때:** `--thermo`나 플레이그라운드의 온도 보기로 확인합니다.

| 증상 | 원인 | 해결 |
|---|---|---|
| 값이 작게 나옴 | 차가움 | 창을 넓히거나 데움 |
| 값이 크게 나옴 | 이웃이 섞임 | 변수를 띄우거나 창을 좁힘 |
| 값이 조금씩 틀림 | 뜨거움 | 창을 좁히거나 타일을 나누거나 쉬는 시간을 넣음 |

### 튜링 완전성

읽기 사이에 `raise`, `lower`로 시간을 보내면 언제든 임계 온도 아래에 머물 수 있습니다. `fermion`을 `2 × lambda` 이상 띄우고 `~1024`로 읽으면서 `raise`, `lower`, 조건문만 쓰면 값은 항상 정확합니다. 값의 크기가 무한하다고 보면 이것으로 2-카운터 머신을 만들 수 있습니다.

[bf.noe](../examples/bf.noe)는 증거가 아닙니다. 테이프가 4096칸입니다. 대신 제곱수를 10000까지 셉니다. 3979만 틱 동안 값이 한 번도 흔들리지 않았습니다. 이전 버전은 9에서 사망했습니다.

## 쓰기

대상은 세 가지로 씁니다.

| 대상 | 뜻 |
|---|---|
| `x` | 그 변수 |
| `a[e]` | 격자 원소. 범위 밖이면 실행 오류 |
| `(e)` | 주소가 정확히 e인 전역 변수 중 가장 먼저 만들어진 것. 없으면 실행 오류 |

| 문장 | 뜻 |
|---|---|
| `\|대상> <- 값` | 쓰기. 값은 정확히 저장됨 |
| `raise 대상` | 1 증가 |
| `lower 대상` | 1 감소 |
| `flip 대상` | 부호 반전 |
| `swap 대상 대상` | 두 변수의 값 교환 |
| `fuse 대상 대상` | 첫째에 둘째를 더함. 같은 공간, 같은 주소가 아니면 실행 오류 |

## 계산

`+`, `-`, `*`, `/` 연산자는 없습니다. 읽기 규칙으로 계산합니다.

**덧셈과 뺄셈:** 같은 주소에 변수를 겹쳐 놓고 그 주소를 읽습니다. 한쪽을 `flip`하면 뺄셈입니다.

```noether
boson a @ 8192
boson b @ 8192
|a> <- 10
|b> <- 3
emit <8192|~1024    # 13
flip b
emit <8192|~1024    # 7
```

**2의 거듭제곱으로 나누기:** 중심에서 벗어나 읽습니다. 폭 1024로 768 벗어나면 `(1024-768)/1024 = ¼`입니다. 창 폭이 `lambda` 이상이어야 온도와 상관없이 일정합니다.

```noether
fermion x
|x> <- 100
emit <x+512|~1024   # 50
emit <x+768|~1024   # 25
```

**곱셈:** `ab = ((a+b)² - (a-b)²) / 4`를 씁니다.

```noether
path mul(a, b)
 boson p @ a
 fermion s @ 8192
 boson u @ s
 |p> <- <b|~64          # a의 주소는 이제 a+b
 |s> <- <a|a>~64        # (a+b)²
 flip p                 # a의 주소는 이제 a-b
 |u> <- <a|a>~64        # (a-b)²
 flip u                 # s의 주소는 이제 4ab
 return <s+768|~1024    # ¼을 읽는다

emit mul(6, 7)          # 42
```

**나눗셈과 나머지:** 겹친 음수를 `fuse`로 반복해서 더합니다. `fuse`는 열이 나지 않습니다.

```noether
path div(x, y)
 fermion q
 boson m @ x
 |m> <- <y|~64
 flip m
 while <x|~64 >= 0
    fuse x m
    raise q
 return <q|~64

path mod(x, y)
 boson m @ x
 |m> <- <y|~64
 flip m
 while <x|~64 >= 0
    fuse x m
 |m> <- 0
 return <x|~64

emit div(17, 5)    # 3
emit mod(17, 5)    # 2
```

**난수:** 좁은 창의 읽기가 난수원입니다. 차가운 변수를 좁게 읽으면 결과는 거의 0이므로, 값을 흔드는 읽기와 확인하는 읽기를 나눕니다. 여러 번 읽으면 범위가 넓어집니다. [guess.noe](../examples/guess.noe)가 예제입니다.

```noether
field seed=random
fermion coin @ 0
fermion scratch @ 8192
|scratch> <- <coin|
if <coin|~1024 > 0
 emit "앞면\n"
else
 emit "뒷면\n"
```

## 제어문

```text
if 값 비교 값
 ...
else
 ...

while 값 비교 값
 ...
```

비교는 `<`, `>`, `<=`, `>=`, `==`, `!=`이고 부호 있는 비교입니다. 조건 안에서 `<-1`은 쓰기가 아니라 -1보다 작다는 뜻입니다. 조건에는 쓸 곳이 없습니다. 조건에는 비교가 꼭 있어야 합니다. `and`, `or`, `break`, `continue`는 없습니다. `while`의 조건은 반복마다 다시 읽으므로 열도 다시 납니다.

## 함수

함수는 `path`로 만듭니다. 깊이 0에만 쓸 수 있고, 선언보다 앞에서 호출해도 됩니다. 재귀도 됩니다.

```noether
path twice(a)
 boson b @ a
 |b> <- <a|~64
 return <a|~64

emit twice(21)      # 42
```

- 호출은 값으로 쓰거나 `f(1)`처럼 문장으로 씁니다.
- `return 값` 또는 `return`으로 돌아옵니다. 값이 없거나 끝까지 가면 0을 돌려줍니다.
- 재귀 깊이는 스택으로 제한됩니다. 컴파일한 프로그램은 1GiB, `--run`은 8GiB입니다. 깊이 500만까지는 확인했습니다.

**함수의 변수 공간:** 호출마다 주소가 0부터 시작하는 별도의 공간이 생깁니다.

- 매개변수는 왼쪽부터 자동 배치된 `fermion`입니다(0, 512, 1024...). 이어서 지역 변수가 만들어집니다.
- 지역 변수 선언은 본문 깊이 1에만 쓸 수 있습니다. 호출 시작에 만들어지고 값은 0입니다.
- `@`의 이름은 이미 선언된 지역 이름만 됩니다.
- 타일은 함수 전체가 하나입니다. 임계 온도의 ¼(기본 1024)로 시작하고, 끝나면 사라집니다.

**이름:** 지역 이름이 전역 이름을 가립니다. 가려지지 않은 전역 변수는 함수 안에서도 읽고 쓸 수 있습니다.

**지역 변수의 주소:** `a`나 `a[1]`을 값으로 꺼내면 컴파일 오류입니다. `<a|~64`, `<a+768|~1024`처럼 읽기와 쓰기 대상으로만 씁니다. `(e)`와 `<8192|`는 함수 안에서도 항상 전역을 가리킵니다.

## 포인터 연산

주소는 정수이므로 변수에 담을 수 있습니다. `(값)`이 값을 다시 주소로 바꿉니다.

```noether
fermion x @ 0
fermion p @ 4096
|x> <- 7
|p> <- x                 # x의 주소를 담는다
emit <(<p|~1024)|~1024   # 7
|(<p|~1024)> <- 8        # x에 8을 쓴다
emit <x|~1024            # 8
```

- `<(e)|`는 변수가 없는 주소도 읽습니다.
- `|(e)>`는 주소가 정확히 일치하는 변수가 있어야 합니다.
- `(e)+100`처럼 숫자를 더하고 뺄 수 있습니다.

`a-b`처럼 주소끼리 직접 빼는 표현식은 없습니다. 주소도 값이므로 겹쳐서 읽습니다.

```noether
fermion a @ 4096
fermion b @ 1024
boson p @ 65536
boson q @ 65536
|p> <- a
|q> <- b
flip q
emit <65536|~1024   # 3072
```

## 대칭 블록

블록에 대칭을 선언하면 컴파일러가 제약을 검사하고 더 빠른 코드를 만듭니다. 어기면 컴파일 오류입니다.

- 블록 안에서는 틱이 멈추고, 그래서 온도도 식지 않습니다.
- 함수 호출과 입력은 쓸 수 없습니다.
- 읽기 규칙은 그대로입니다.

### symmetry time

되돌릴 수 있는 연산만 쓰는 블록입니다. 안에서는 읽기도 열을 내지 않습니다. 그래서 좁은 창은 차가운 채로 일부만 읽으니 `~1024`를 씁니다.

값을 0이 될 때까지 `lower`하는 것도 되돌릴 수 있는 연산으로 칩니다. 아무도 되돌리려고 하지 않았기 때문입니다. 지운 비트에 대한 열은 청구되지 않습니다.

```noether
fermion i
|i> <- 1000
symmetry time
 while <i|~1024 > 0
    lower i
emit <i|~1024       # 0
```

| 허용 | 금지 |
|---|---|
| `raise`, `lower`, `flip`, `swap`, `fuse` | 쓰기 |
| `if`, `else`, `while` | `emit`, `emitc`, `emitn` |
| 조건과 인덱스 안의 읽기 | `return` |
| 중첩된 `symmetry time` | `symmetry translate` |

### symmetry translate

전역 격자의 원소마다 본문을 실행합니다. `k`는 0부터 길이-1까지 늘어납니다.

```noether
fermion a[4] @ 0 stride 4096
boson   b[4] @ a stride 4096
fermion c[4] @ 65536 stride 4096
|a[3]> <- 4
|b[3]> <- 40
symmetry translate k in a
 |c[k]> <- <a[k]|~1024
emit <c[3]|~1024    # 44
```

- 격자 인덱스는 정확히 `k`만 됩니다. 쓰는 격자는 전역이고 길이가 `a` 이상이어야 합니다.
- 값을 바꿀 수 있는 것은 `격자[k]`뿐입니다.
- 쓸 수 있는 문장은 쓰기, `raise`, `lower`, `flip`, `swap`, `fuse`, `if`, `else`입니다.
- `(e)` 주소는 쓸 수 없습니다.
- 열은 평소대로 계산하지만 블록이 끝날 때 한꺼번에 넣습니다. 반복해서 실행하려면 사이에 틱을 흘려야 합니다.

### 빠른 코드의 조건

컴파일러는 대칭 블록을 두 벌 만들고 진입 시 고릅니다. 결과는 항상 같습니다. 빠른 코드는 다음을 모두 만족할 때 실행됩니다.

- 블록의 모든 읽기가 `hbar`보다 넓은 창을 씁니다.
- `(e)` 주소가 없습니다.
- 진입 시점에 관련된 타일이 모두 정확 구간 안입니다.

## 입출력

| 문법 | 뜻 |
|---|---|
| `emit 값` | 10진수와 줄바꿈을 출력 |
| `emitn 값` | 10진수만 출력 |
| `emit "문자열"` | 문자열을 그대로 출력. 줄바꿈 없음 |
| `emitc 값` | 값의 하위 8비트를 1바이트로 출력 |
| `absorb` | 입력에서 한 줄을 읽어 정수로 변환. 실패하거나 입력이 끝나면 0 |
| `absorbc` | 1바이트를 읽음. 입력이 끝나면 -1. `\r\n`은 `\n` 한 바이트로 읽음 |

`absorb`로는 입력이 끝났는지 알 수 없습니다. 입력이 끝난 것과 0을 입력한 것은 같은 일입니다. 끝을 알아야 하는 프로그램은 0을 포기로 정합니다. [guess.noe](../examples/guess.noe)가 그렇게 합니다.

문자열 변수는 없습니다. 입력받은 글자를 저장하려면 격자에 바이트로 넣습니다. [name.noe](../examples/name.noe)가 예제입니다.

## 실행 순서

- 전역 변수를 만든 뒤 깊이 0의 문장을 위에서 아래로 실행합니다.
- 표현식은 왼쪽에서 오른쪽으로 평가합니다. 읽기는 주소 안의 표현식을 먼저 평가합니다.
- 쓰기는 대상 확정, 오른쪽 값 평가, 틱 증가, 열, 저장 순입니다.
- 호출은 인수를 왼쪽부터 평가한 뒤 변수 공간을 만듭니다.

## 문법 정의

`BLOCK`은 한 단계 깊어진 문장들입니다.

```ebnf
program   = { field | decl | path | stmt } ;
field     = "field" { NAME "=" (INT | "random") } ;
decl      = ("fermion" | "boson") NAME [ "[" INT "]" ] [ "@" place ]
            { "stride" INT } ;
place     = INT | NAME [ ("+" | "-") INT ] ;
path      = "path" NAME "(" [ NAME { "," NAME } ] ")" BLOCK ;

stmt      = ket "<-" value
          | ("raise" | "lower" | "flip") target
          | ("swap" | "fuse") target target
          | "if" cond BLOCK [ "else" BLOCK ]
          | "while" cond BLOCK
          | "symmetry" "time" BLOCK
          | "symmetry" "translate" NAME "in" NAME BLOCK
          | "emit" (value | STRING)
          | "emitc" value
          | "emitn" value
          | "return" [ value ]
          | call ;

ket       = "|" target ">" ;
target    = NAME | NAME "[" value "]" | "(" value ")" ;
cond      = value ("<" | ">" | "<=" | ">=" | "==" | "!=") value ;
value     = INT | "-" INT | bra | intensity | call | addr
          | "absorb" | "absorbc" ;
bra       = "<" addr "|" [ window ] ;
intensity = "<" addr "|" addr ">" [ window ] ;
window    = "~" INT ;
call      = NAME "(" [ value { "," value } ] ")" ;
addr      = INT | target [ ("+" | "-") INT ] ;
```

## 오류

컴파일 오류의 종료 코드는 2입니다. [들여쓰기](#들여쓰기) 오류 외의 메시지는 다음과 같습니다.

| 오류 메시지 | 원인 |
|---|---|
| `bad character` | 쓸 수 없는 문자 |
| `does not fit in 64 bits` | 정수가 범위를 넘음 |
| `unknown escape`, `unterminated string` | 문자열 오류 |
| `is not a power of two`, `limited to 2^30` | 창 폭이나 `field` 값이 맞지 않음 |
| `only seed can be random` | `seed` 외의 설정에 `random`을 씀 |
| `unknown field parameter`, `unknown attribute`, `unknown symmetry` | 없는 설정 이름 |
| `unknown name`, `unknown path` | 없는 변수나 함수 |
| `declared twice` | 이름 중복 |
| `used with the wrong shape` | 격자가 아닌 것에 인덱스를 씀 |
| `used as a single packet` | 격자 이름을 쓰기 대상으로 씀 |
| `is already a law of nature` | 키워드를 함수 이름으로 쓰거나 `absorb`, `absorbc`를 변수 이름으로 씀 |
| `tmin is limited to 2^62` | `tmin`이 온도의 상한을 넘음 |
| `takes N arguments` | 인수 개수가 다름 |
| `a boson must be placed` | `boson`에 `@`가 없음 |
| `Pauli violation` | `fermion`끼리 너무 가까움 |
| `declarations only at the top of a path` | 블록 안에서 선언함 |
| `belongs at the top level` | `field`나 `path`를 블록 안에 씀 |
| `return outside a path` | 함수 밖의 `return` |
| `closed system` | 지역 변수의 주소를 꺼내거나 대칭 블록에서 호출, 입력을 씀 |
| `symmetry time broken`, `symmetry translate broken` | 대칭 블록에서 금지된 것을 씀 |
| `may only be used as a subscript` | `k`를 인덱스 밖에서 씀 |
| `is shorter than the sweep` | 격자 길이가 모자람 |
| `is not a global lattice` | `translate` 대상이 전역 격자가 아님 |
| `intensity needs the same address` | 제곱 읽기의 양쪽이 다름 |
| `expected`, `unexpected`, `cannot start a statement` | 그 외 문법 오류 |

실행 오류의 종료 코드는 3이고, 그때까지의 출력은 남습니다.

| 오류 메시지 | 원인 |
|---|---|
| `index N is outside lattice` | 인덱스가 범위 밖 |
| `write into vacuum` | `(e)` 대상 주소에 변수가 없음 |
| `fuse needs two packets at the same centre` | `fuse`의 두 변수가 다른 주소에 있음 |

## 컴파일러

```bash
noetherc 파일.noe -o 출력.exe
```

| 옵션 | 뜻 |
|---|---|
| `--run` | 실행 파일을 만들지 않고 바로 실행 |
| `--thermo` | 온도를 `출력.thermo.csv`에 기록하고 끝날 때 요약을 출력 |
| `--stats` | 읽기 수와 대칭 블록 수 출력 |
| `--no-symmetry` | 대칭 블록의 빠른 코드를 만들지 않음 |
| `--no-isolate` | 모든 읽기를 일반 경로로 실행 |

시드가 고정이면 어떤 옵션을 써도 결과는 같습니다.

종료 코드는 0 정상, 2 컴파일 오류, 3 실행 오류, 64 잘못된 명령행, 66 소스를 읽지 못함, 70 코드 생성이나 링크 실패, 73 출력 파일을 쓰지 못함입니다.

## 예제

전부 실행해서 확인한 코드입니다.

### 온도

**온도에 따라 달라지는 읽기.** 따뜻할 때는 폭이 좁아서 정확하고, 식으면 일부만 읽히며 이웃도 섞입니다.

```noether
field seed=7
boson p @ 100000
boson q @ 100300
fermion c @ 0
|p> <- -1
|p> <- 1000
|p> <- -1
|p> <- 1000
|p> <- -1
|p> <- 1000
|q> <- 2000
emit <p|~64       # 1000: 따뜻해서 폭이 좁다
|c> <- 3000
while <c|~1024 > 0
 lower c
 lower c
 raise c
emit <p|~64       # 228: 식어서 일부만 읽히고 q도 섞인다
emit <p|~1024     # 2414: 전부 읽히지만 q가 724/1024만큼 섞인다
```

**반복 읽기를 함수로 옮기기.** 전역 변수를 한 번만 읽어 인수로 넘기면, 반복 읽기의 열이 함수 안에 쌓였다가 사라집니다.

```noether
fermion g
|g> <- 7

path twice(v)
 boson b @ v
 |b> <- <v|~64
 return <v|~64

emit twice(<g|~1024)    # 14
```

**스스로 데워지는 창.** `~256`은 데우기 코드 없이 쓸 수 있습니다. 온도 16 이상이면 변수 폭이 256 이하라 간격 512의 이웃도 닿지 않습니다. 다만 열이 16배이므로 깊은 반복에서 자주 읽으면 임계 온도를 넘습니다.

```noether
fermion a
fermion b
|a> <- 1000
|b> <- 2000
emit <a|~256       # 1000
emit <b|~256       # 2000
```

### 값

**두 값 정렬.** 쓰기 대신 `swap`을 쓰면 열이 없고 대칭 블록에 넣을 수 있습니다.

```noether
fermion a @ 0
fermion b @ 4096
|a> <- 9
|b> <- 3
symmetry time
 if <a|~1024 > <b|~1024
    swap a b
emit <a|~1024      # 3
emit <b|~1024      # 9
```

**절댓값.**

```noether
fermion x
|x> <- -42
if <x|~1024 < 0
 flip x
emit <x|~1024      # 42
```

**두 배 만들기.** 같은 주소에 같은 값을 겹칩니다.

```noether
fermion x
boson copy @ x
|x> <- 21
|copy> <- <x|~1024
emit <x|~1024      # 42
```

**최대공약수.** 재귀는 호출마다 따뜻한 변수 공간을 새로 받으므로 온도 걱정이 적습니다.

```noether
path mod(x, y)
 boson m @ x
 |m> <- <y|~64
 flip m
 while <x|~64 >= 0
    fuse x m
 |m> <- 0
 return <x|~64

path gcd(a, b)
 if <b|~64 == 0
    return <a|~64
 return gcd(<b|~64, mod(<a|~64, <b|~64))

emit gcd(48, 18)   # 6
```

**소수 세기.** `prime`을 오래 호출하는 동안에도 틱이 흘러서, 돌아오면 `count`의 변수 공간이 식어 있습니다. `~64`로 읽으면 값의 일부만 읽혀서 답이 5로 나오고, `~1024`로 읽으면 열이 너무 많아 답이 22로 나옵니다. 스스로 데워지는 `~256`이 맞습니다. `count(100)`은 24, `count(1000)`은 157입니다. 소수는 원래 드뭅니다.

```noether
path mod(x, y)
 boson m @ x
 |m> <- <y|~64
 flip m
 while <x|~64 >= 0
    fuse x m
 |m> <- 0
 return <x|~64

path prime(n)
 fermion d
 |d> <- 2
 while <d|~256 < <n|~256
    if mod(<n|~256, <d|~256) == 0
         return 0
    raise d
 return 1

path count(limit)
 fermion n
 fermion total
 |n> <- 2
 while <n|~256 <= <limit|~256
    if prime(<n|~256) == 1
         raise total
    raise n
 return <total|~256

emit count(30)     # 10
```

**FizzBuzz.** 100줄 중 99줄이 맞습니다. 94번째 줄에는 47이 나옵니다. `mod`를 세 번 도는 사이에 프레임이 식어서 절반만 읽힌 것입니다. 경고는 없습니다. `emit <n|~256`으로 고치면 94가 나오지만, 99점이면 합격입니다.

```noether
path mod(x, y)
 boson m @ x
 |m> <- <y|~64
 flip m
 while <x|~64 >= 0
    fuse x m
 |m> <- 0
 return <x|~64

path fizz(n)
 if mod(<n|~64, 15) == 0
    emit "FizzBuzz\n"
    return
 if mod(<n|~64, 3) == 0
    emit "Fizz\n"
    return
 if mod(<n|~64, 5) == 0
    emit "Buzz\n"
    return
 emit <n|~64

fermion i
|i> <- 1
while <i|~256 <= 100
 fizz(<i|~256)
 raise i
```

**피보나치.** 두 변수를 겹치면 그 주소가 곧 다음 항입니다. `fuse`와 `swap`만 쓰므로 전부 대칭 블록에 들어갑니다.

```noether
boson a @ 0
boson b @ 0
fermion n @ 8192
raise b
|n> <- 10
symmetry time
 while <n|~1024 > 0
    fuse a b
    swap a b
    lower n
emit <0|~1024      # 144
```

### 격자와 문자

**격자 전체를 한 번에.** `symmetry translate`로 모든 원소에 같은 일을 합니다.

```noether
fermion a[4] @ 0 stride 4096
symmetry translate k in a
 |a[k]> <- 7
emit <a[3]|~1024   # 7
```

**격자 합계.** 인덱스와 합계는 타일을 나누고, 격자는 `~1024`로 읽습니다.

```noether
fermion a[5] @ 0 stride 4096
boson x @ 65536
boson y @ 65536
fermion i @ 73728
|a[0]> <- 1
|a[1]> <- 2
|a[2]> <- 3
|a[3]> <- 4
|a[4]> <- 5
while <i|~1024 < 5
 |y> <- <a[<i|~1024]|~1024
 fuse x y
 raise i
 |y> <- 0
emit <65536|~1024  # 15
```

**글자 출력.** `emitc`로 글자 코드를 내보냅니다. 아래 프로그램은 `ABCDE`를 출력합니다. UTF-8 바이트를 차례로 내보내면 한글도 출력됩니다.

```noether
fermion c
|c> <- 65
while <c|~1024 <= 69
 emitc <c|~1024
 raise c
emitc 10
```

**출력 섞어 쓰기.** 아래 프로그램은 `Hi`와 `7 x 6 = 42`를 출력합니다.

```noether
emitc 72
emitc 105
emitc 10
emitn 7
emit " x "
emitn 6
emit " = 42\n"
```

**주사위.** 값을 흔들고, 절댓값을 취한 뒤, 나머지를 구합니다. 한 번의 좁은 창 읽기는 고른 분포이지만, 여러 번 누적하면 가운데로 몰립니다.

 |m> <- <y|~64

 while <x|~64 >= 0
    fuse x m
 |m> <- 0
 return <x|~64

|s> <- <r|
|s> <- <r|
|s> <- <r|
if <r|~1024 < 0
 flip r
|v> <- mod(<r|~1024, 6)
raise v
emit <v|~1024
